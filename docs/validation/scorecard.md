# Validation scorecard

Create one copy per buyer conversation. Record observed facts and exact buyer
language rather than optimistic interpretation.

## Conversation record

```text
Organization:
Date:
Participants and roles:
CMS/estate:
Current initiative:
Decision deadline:
Interviewer:
```

## Qualification

Score each item from 0 to 2.

| Signal | 0 | 1 | 2 | Score |
| --- | --- | --- | --- | --- |
| Active trigger | General interest | Possible future work | Active funded/dated decision | |
| Problem severity | No clear consequence | Friction or uncertainty | Budget, schedule, compliance, or outage impact | |
| Sponsor | Unknown | Influencer engaged | Decision owner engaged | |
| Evidence access | No path | Partial/uncertain | Approved export, collector, or read-only path | |
| Output value | Nice inventory | Useful planning input | Changes a material decision | |
| Timing | More than 12 months | 3–12 months | Within 90 days | |
| Commercial path | No budget/path | Path unclear | Budget and procurement path identified | |
| Repeatability | Highly unique | Some common needs | Matches needs seen elsewhere | |

```text
Total (maximum 16):
```

Interpretation:

- **12–16:** qualified pilot candidate;
- **8–11:** continue discovery and resolve missing sponsor/access/value;
- **0–7:** do not build for this opportunity yet.

The score supports judgment; it does not replace it.


## Outcome

Choose one:

- draft a paid pilot;
- request a technical evidence session;
- seek introduction to the sponsor;
- schedule follow-up around a dated trigger;
- decline or archive.

Record the next action, owner, and date. A conversation without a concrete next
step is learning, not pipeline.
